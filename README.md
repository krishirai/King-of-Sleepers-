# King of Sleepers 😴👑

A Flutter app built as a project for AUT (Auckland University of Technology) that helps students find a good place to take a nap on campus.

## Features

- Sign in with email/password or Google
- Browse nap spots with their location and available seats
- See your current nap spot on a map and get directions
- Rate the nap spots you've tried

## How to run

Requires the [Flutter SDK](https://docs.flutter.dev/get-started/install).

1. Clone the repository: `git clone https://github.com/krishirai/King-of-Sleepers-.git`
2. Go into the project folder: `cd King-of-Sleepers-`
3. Install the dependencies: `flutter pub get`
4. Run the app: `flutter run`

## Built with

Flutter, Firebase Authentication, Cloud Firestore and flutter_map.
